Sewing Projects

A small collection of personal sewing works.

Ruffled Collar Shirt Transformation

This project started with a shirt a friend gave me. I shortened the body and sleeves, removed the original collar and used the leftover fabric to create a larger ruffled collar. Because there was not enough fabric, I added a second layer underneath for a small peekaboo effect. I added elastic to the sleeves to make them puffier, then tightened the back with a corset-style detail to improve the fit.

Linen Matching Set

I wanted to create a playful matching set, so I turned second-hand fabric into a blouse and a pair of trousers. For the trousers, I followed Thuy Phan’s tutorial for DIY half-elastic-waistband linen culotte pants. For the top, I used her tutorial for a beautiful V-neck collar with lace and front buttons. I crocheted the lace detail myself because I could not find a trim I liked. I am very happy with the result, especially the trousers, which I would like to make again in other fabrics.

Pink Gingham Detachable Collar

This project is a pink gingham detachable collar designed to be worn with different outfits. I had seen several examples of this accessory and wanted to create one that would work with my wardrobe. It was one of my first projects using ruffles, and I immediately fell in love with them. The fabric came from my trusted market stall and reminded me of Barbie’s beach dress. Since I did not have enough fabric for a complete garment, I made a smaller accessory that still reflects my style.
